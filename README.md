# hxwl-09 半导体洁净室跨班互检与仪器漂移复核台

巡检员按房间与班次登记粒子计数、压差、温湿度及仪器编号，系统完成跨班互检、
仪器漂移复核与修订版本管理，重开页面仍能完整还原三类关系。

## 业务规则

- **登记唯一**：同房间 + 同日期 + 同班次只保留一条生效记录。
  - 互检通过的条目允许本班重新登记并重新判定；
  - 待复核 / 已升级条目禁止直接重填；冻结条目禁止覆盖。
- **跨班互检**：每次登记自动与同房间相邻上一班（跨天 A→B→C 连续排序）的生效读数比对。
  - 粒子计数（≥0.5µm）：绝对变化 ≥500 粒/m³ **且** 相对变化 ≥25%；
  - 压差 ≥3Pa、温度 ≥1℃、湿度 ≥5%RH。
- **漂移复核**：任一指标越限，条目停在「待复核」并**保留原值原仪器**；
  由下一班更换**另一台合格仪器**复测（粒子计数器 / 差压计 / 温湿度仪逐组校验换机）。
  - 复测值与原值在阈值内 → **通过**：复测仪器与复测值生效并**冻结**；
  - 仍越限 → **未过**：保留原值并升级厂务。
- **更正**：冻结值不可改；任何更正都**另建带原因的版本**（v1→v2…），
  原记录保留为历史；升级单作为处置留档并挂更正指针。
- **粒子超限**与漂移是两件事：读数超过房间等级限值会单独标「超限」，不影响互检流程。

## 分层结构

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 领域数据 | `src/domain/types.ts`、`src/domain/config.ts` | 类型、房间等级、班次、仪器台账、阈值 |
| 判定 | `src/domain/policy.ts` | 漂移判定、仪器合格/换机校验、复测判定（纯函数） |
| 存储 | `src/storage/repository.ts`、`src/storage/seed.ts` | localStorage 持久化、首屏演示数据 |
| 状态 | `src/state/useBoard.ts`、`src/state/selectors.ts` | 登记 / 复测 / 更正动作与关系派生 |
| 页面 | `src/components/*`、`src/App.tsx` | 录入、复核队列、台账、三类关系视图 |

## 页面分区

1. 指标卡：生效条目 / 待复核 / 已冻结 / 已升级 / 更正版本数
2. 巡检登记（房间、日期、班次、巡检员、三类仪器、四项读数）
3. 漂移复核台（待复核条目可直接录入换机复测；升级条目发起更正）
4. 巡检台账（按房间/状态/巡检员筛选，展开看互检、复核、修订明细）
5. 关系视图：
   - 跨班互检链（同房间班次时间线，漂移点高亮）
   - 漂移复核闭环（漂移 → 换机复测 → 冻结 / 升级 → 更正）
   - 修订谱系（版本链与更正原因）

## 技术栈

React 19 + Vite + TypeScript + 原生 CSS；数据保存在浏览器 localStorage
（键 `hxwl-09.cleanroom-board.v1`），页面右上角可一键重置为演示数据。

## 本地运行

```bash
npm install
npm run dev      # 开发：http://localhost:5109
npm run build    # 类型检查后构建
npm run preview  # 预览构建产物
```

## 后续可扩展
