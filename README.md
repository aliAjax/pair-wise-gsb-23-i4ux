# hxwl-09 洁净室跨班互检与仪器漂移复核台

半导体洁净室巡检看板：按房间和班次登记读数，相邻班互检漂移，下一班换仪器复测，更正走带原因的修订版本。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 业务规则

- **登记**：巡检员按房间 + 班次登记粒子计数、压差、温湿度及仪器编号；同房间同班只留一条当前记录（未进入流程的记录可被替换，已冻结/已复核的只能修订）。校准超期的仪器禁止登记。
- **互检**：新记录与同房间上一班比对，任一指标越过漂移阈值（粒子 ±30%、压差 ±5 Pa、温度 ±2 ℃、湿度 ±5 %RH）即停在「待复核」并保留原值。
- **复测**：须由下一班、换另一台合格仪器执行；复测值与原值在阈值内 → 通过并冻结仪器与读数；否则记录保持待复核，可再测或修订。
- **修订**：更正不改动原记录，另建 version+1 并必填原因，原版本标记「已被修订」保留在版本链中；新版本重新参与互检判定。
- **持久化**：全部状态存于 localStorage，重开页面后互检、漂移复核、修订关系完整保留。

## 分层结构

```
src/
  domain/    领域数据与判定（纯函数，不碰存储和页面）
    types.ts     记录、读数、仪器、状态机
    shifts.ts    班次推算（相邻班）
    judgment.ts  漂移阈值与登记/复测/修订规则
    seed.ts      示例数据（重放领域操作生成）
  storage/   localStorage 读写
  ui/        登记面板、记录看板、读数录入
  App.tsx    页面组装
```
